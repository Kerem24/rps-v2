# Rock Paper Scissors

A simple Rock Paper Scissors game that runs in the browser. Play against the computer, first to 5 points wins.

## How to play

1. Pick rock, paper or scissors.
2. The computer picks randomly.
3. Rock beats scissors, scissors beats paper, paper beats rock.
4. First to 5 points wins the match. Hit "Play" to start again.

## Run it

No install needed. Download or clone the repo and open `index.html` in your browser.

```bash
git clone <your-repo-url>
cd rock-paper-scissors
```

## Built with

HTML, CSS and vanilla JavaScript.
